# Learning React

This workspace contains simple React practice files and a Vite setup path.

## Current files

- `index.html`, `index.jsx`, `index.css` (Live Server-style setup)
- `Header.jsx`
- `my-react-vite-app/` (Vite app folder)

## Run with Live Server

1. Open `index.html`
2. Start **Go Live**
3. Make sure `index.jsx` does not use ES module imports unless using a bundler.

## Run with Vite (recommended)

From project root:

1. `cd my-react-vite-app`
2. `npm.cmd install`
3. `npm.cmd run dev`

Then open the local URL shown in terminal (usually `http://localhost:5173`).

## Notes

- On Windows PowerShell with execution policy restrictions, prefer `npm.cmd` instead of `npm`.
- If a page is blank, check browser DevTools Console for JSX/import errors.
