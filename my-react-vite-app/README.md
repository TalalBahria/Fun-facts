# My React Vite App

This project is a simple React application bootstrapped with Vite. It serves as a starting point for building modern web applications using React.

## Features

- Fast development with hot module replacement (HMR)
- Optimized build for production
- Easy to configure and extend

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd my-react-vite-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

   This will start the Vite development server and open your application in the browser.

## Building for Production

To create a production build of your application, run:

```bash
npm run build
```

This will generate optimized static files in the `dist` directory.
